# Curved Space · Geometry Lab

Standalone WebGL2 visualization of parallel transport, geodesic construction,
geodesic deviation, and tidal forces. Open `index.html` through an HTTP server
(VS Code Live Server works); there is no build step or runtime dependency.

Published copy of ParallelTransportSphere, source commit `3dc6b10`, added on
2026-09-28. Runtime files are copied without modification. The development
project and its tests remain separate from this homepage copy.

Adjustable experiment settings live in `js/config.js`; GLSL shaders are in
`shaders/`. The homepage gallery uses `../thumbnails/curved-space.webp`, an
actual screenshot of the parallel-transport experiment.
