Wave, spin & guidance

One spinor Ψ = (ψ↑, ψ↓) has N×N orthogonal spatial packets in each spin channel. Labels are |x,y,spin⟩, with x and y from 0 to N−1. Choose the input |i⟩ first and the goal |w⟩ second on the main wave grid, following the guide above it, or run with the current selections. Each colored box contains overlapping tails, so its spatial probability differs from its logical-mode probability.

A = Ubox(T) ⊗ Ry(π/2)
A† = Ubox((2N−1)T) ⊗ Ry(−π/2)

The spatial mixer uses exact free-box evolution. T = Trev/(2N). The imposed uniform spin-only drive is reversed during the forward (2N−1)T wait. The oracle phases the red goal |w⟩; the reference phases the selected green input |i⟩. Thus D = A Sᵢ A† reflects about A|i⟩. The search uses the first optimal Grover peak: 2, 3, 4 or 5 iterations for grids of size 2, 3, 4 or 5.

ρ = |ψ↑|² + |ψ↓|²
jP = (ℏ/m) Im(Ψ†∇Ψ) + (1/m) ∇×(ρs)
∇×(ρs) = ∇ρ × s + ρ ∇×s
v = jtotal / ρ

The full spinor gradients include spin-texture effects. This planar model uses the in-plane magnetization current (ℏ/2m)(∂ᵧMz, −∂ₓMz), with Mz = |ψ↑|² − |ψ↓|². It describes reduced planar flow, not all possible transverse motion in a three-dimensional trap.

Free intervals use the Pauli current. Ideal mode-selective phase pulses are spatially nonlocal: we choose jtotal = jP + ∇u, with Δu = −∂ₜρ − ∇·jP and zero wall flux. This generalized guidance conserves density and retains spin circulation; it is not a unique local-Pauli implementation of those gates.

Particles sample total position density; they have no permanently assigned up/down label. Compare their fraction inside the box with the spatial probability, not the joint marked-mode probability. Changing wave or arrow views leaves their motion unchanged. Pause and gate checkpoints freeze the simulation clock.
