About the wave and gates

Each box labels an orthogonal logical mode built from N sine eigenmodes along each axis, with N selectable from 2 to 5. Packets overlap, so the probability of a logical mode differs from probability inside its geometrical box.

Labels use binary position registers for 2×2 and 4×4, and |x,y⟩ for 3×3 and 5×5. Columns increase left to right; rows increase bottom to top. Choose the initial mode |i⟩ and the goal on the main wave using the guide beside the title. The default initial mode is |0000⟩. The reference phase acts on the chosen |i⟩, so the diffuser reflects about H|i⟩.

H = HHad⊗2log₂N (N = 2, 4)
Hxy,uv = e2πi(xv−yu)/N/N (N = 3, 5)
ℋmix = πℏ(I − H)/(2T)

Both mixers satisfy H† = H and H² = I, with equal probabilities from every input. Preparation and forward mixing use exp(−iℋmixt/ℏ); inverse mixing uses the opposite sign. Phase gates use exact mode-projector exponentials. These are ideal mode operations, rather than free-box propagation. The wave evolves unitarily at every instant.

The first optimal Grover peak takes 1, 2, 3 or 3 iterations for 2×2, 3×3, 4×4 or 5×5 respectively. All gates and the wave hold still at checkpoints and when paused.

The arrows show a conserved spatial current derived from the exact density change, with zero flow through the outer walls. We choose the curl-free solution. This is a generalized probability-transport model; the nonlocal gate Hamiltonian does not uniquely determine continuous particle paths.

Particle fractions sample the spatial density and should track “Inside goal box.” Arrow length indicates current strength, with a compressed display scale. Pause freezes the instantaneous arrows and all trajectories for inspection.
